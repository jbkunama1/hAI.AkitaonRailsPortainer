GitHub Repository

Web-UI

Der Portainer-Stack aktiviert die Web-UI mit folgendem Startbefehl im Service ai-memory:

command:
  - serve
  - --transport
  - http
  - --enable-web

Kein zusätzliches ai-memory vor serve: Das Image startet das Programm bereits über seinen Entrypoint.

Aufruf nach dem Redeploy

http://<server-ip>:49374/web

Bei abweichendem AI_MEMORY_PORT den konfigurierten Port verwenden. Server-IP bzw. Hostname müssen zur bestehenden AI_MEMORY_ALLOWED_HOSTS-Konfiguration passen. Diese Projektseite ist nur Dokumentation; die Web-UI läuft auf deinem Server.

Login

Für den einfachen Root-Token-Login ohne eingerichtete Benutzerkonten: beliebiger Benutzername, Passwort = Wert von AI_MEMORY_AUTH_TOKEN. Bei bestehenden Benutzerkonten deren Zugangsdaten verwenden.

Den bestehenden Token beibehalten oder einen starken, nicht leeren Wert in Portainer setzen. Keine zusätzliche Web-UI-ENV erforderlich. Tokens nicht ins Repository schreiben. Für Internetzugriff HTTPS über einen Reverse Proxy verwenden.

Die Web-UI verwendet denselben Dienst und Port. Volume und übrige Umgebung bleiben für die Aktivierung unverändert.
